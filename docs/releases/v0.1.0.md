# EchoMind v0.1.0 Beta

首个可下载运行的 macOS 发布包。

## 下载与启动

下载 `EchoMind-0.1.0-macos-x64.zip`，解压后双击 `Start EchoMind.command`。浏览器会自动打开 EchoMind；保持终端窗口运行，关闭窗口即可停止本机服务。首次练习时请允许浏览器使用麦克风。

发布包面向 macOS Intel（x64）。Apple Silicon 用户需要 Rosetta 2。包内已含 Node.js 运行环境和中文 Zipformer 本地语音模型，不需要安装 pnpm 或另外下载语音模型。

模型生成的问题及分析报告需要自行配置兼容 OpenAI Chat Completions 的服务。发布包没有预置在线大模型或 API Key。

## 本版内容

- 模拟面试和工作汇报练习；浏览器内录音与本地实时转写。
- 可修订语义稿、整场及逐题分析、评分、表达习惯统计与独立 HTML 报告导出。
- 练习历史、麦克风测试与默认设备、多种主题风格。

完整变更参见 [更新日志](../../CHANGELOG.md)。

## 模型来源

内置 `sherpa-onnx-streaming-zipformer-zh-int8-2025-06-30` 的 encoder、decoder、joiner 和 tokens 文件；[sherpa-onnx 下载页面](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-transducer/zipformer-transducer-models.html)，[原始模型](https://huggingface.co/yuekai/icefall-asr-multi-zh-hans-zipformer-large)。
