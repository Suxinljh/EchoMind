# EchoMind v0.1.1 Beta

第二个可下载运行的 macOS 发布包，重点是修掉 v0.1.0 里会卡住流程或让页面打不开的稳定性问题，并改善了长时间录音和语义稿编辑的流畅度。

## 下载与启动

下载 `EchoMind-0.1.1-macos-x64.zip`（约 170 MB），解压后双击 `Start EchoMind.command`。浏览器会自动打开 EchoMind；保持终端窗口运行，关闭窗口即可停止本机服务。首次练习时请允许浏览器使用麦克风。

发布包面向 macOS Intel（x64）。Apple Silicon 用户需要 Rosetta 2。包内已含 Node.js 运行环境和中文 Zipformer 本地语音模型，不需要安装 pnpm 或另外下载语音模型。

模型生成的问题及分析报告需要自行配置兼容 OpenAI Chat Completions 的服务。发布包没有预置在线大模型或 API Key。

## 本版修复

- **结束后不再卡在“正在收尾转写…”**：语音模型出错时会显示原因，超过 15 秒没有返回时也会给出当前结果；工作线程异常退出同样会被捕获。
- **“重新转写”不再无反应**：模型未就绪或缓冲为空时会明确提示，而不是静默失败。
- **长时间录音内存可控**：录音缓冲上限为 20 分钟，超出部分不再保留并在界面上说明；确认回答后立即释放缓冲，切换练习时在途的评估请求会被取消。
- **本地历史损坏不再导致白屏**：练习历史改为逐条校验后读取，损坏条目会被跳过；新增渲染错误兜底页面，可一键清除本地练习数据。
- **更新日志恢复显示「发布」条目**：此前这类条目会被静默丢弃，现在有独立的筛选分类。
- **打开报告不再误报被拦截**：浏览器正常打开新标签页时不再提示“已被拦截”。
- **两条模型代理路径行为一致**：云端与本机共用同一套请求校验、地址校验和 API Key 隐藏规则；客户端断开时云端会同时中止上游请求，避免无谓计费。
- **打包不会产出不完整的包**：`pnpm package:macos` 在复制前校验 `dist/` 里的页面与四个语音模型文件，缺失时直接报错且不产出 zip；`pnpm build` 现在会显式准备语音模型。
- **本机服务支持缓存校验**：模型文件与带内容哈希的静态资源返回对应的 `Cache-Control`，并提供 ETag / Last-Modified，重复请求可直接得到 304。

## 本版优化

- 语义稿改为停止输入后提交，不再每敲一个字就重算评分并重写全部历史；浏览器存储改为合并写入。
- 实时转写与输入电平合并刷新，长时间录音时页面更流畅。

完整变更参见 [更新日志](../../CHANGELOG.md)。
